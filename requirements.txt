# VLCFusion — dependency overview
#
# This project uses TWO separate, mutually-incompatible Python environments
# (different torch / numpy / CUDA stacks). Do NOT install both into one env.
#
#   ┌─────────────────────┬──────────────────────────────────────────────────────────┐
#   │ ATR experiment      │ HuggingFace DETR (MultimodalDetr).                        │
#   │  env: gen_ai        │   ->  ATR Experiment/requirements.txt                     │
#   │                     │       ATR Experiment/requirements.lock.txt  (exact freeze)│
#   ├─────────────────────┼──────────────────────────────────────────────────────────┤
#   │ Waymo experiment    │ mmdet3d + Waymo Open Dataset devkit.                      │
#   │  env: waymo         │   ->  Waymo Experiment/requirements.txt                   │
#   │                     │       Waymo Experiment/requirements.lock.txt (exact freeze)│
#   └─────────────────────┴──────────────────────────────────────────────────────────┘
#
# Each per-experiment requirements.txt has the guided install order (PyTorch ->
# OpenMMLab/HF -> the rest); the .lock.txt is a full `pip freeze` for byte-exact clones.
#
# Two gotchas captured in the Waymo file:
#   * protobuf: env has 4.25.8 (upb) which breaks the devkit's bytearray parsing —
#     use protobuf==3.20.* OR PROTOCOL_BUFFERS_PYTHON_IMPLEMENTATION=python.
#   * Official Waymo metric binary: see Waymo Experiment/WAYMO_EVAL_SETUP.md.
